# Persona review: M9 compatibility and polish (2026-10-24)

Reviewers: Senior Engineer, Ethical Hacker (also covering the Security Architect's checklist).

| # | Finding (who) | Severity | Resolution |
|---|---|---|---|
| 1 | `vncserver` ran before the root refusal; as root with a user's environment it followed symlinks in the user's runtime dir (EH) | Major (conditional) | **Fixed:** root refused first for every personality; private 0700 state dir checked; log/pid files opened owner-only with `O_NOFOLLOW` |
| 2 | `vncserver -kill` trusted any pid whose cmdline contained "headless" (SE, EH) | Major | **Fixed:** the process must be this executable serving that display |
| 3 | Concurrent `vncserver` runs raced on the display and pidfile; `-kill` returned before exit (SE, EH) | Major/Minor | **Fixed:** exclusive pidfile claim; `-kill` waits |
| 4 | Physical keys assumed evdev keycodes on every X server (SE) | Major | **Fixed:** checked on layout-independent keys; otherwise falls back to the keysym |
| 5 | Keys held by a viewer that drops stayed down on live desktops; Wayland didn't track them (EH) | Major | **Fixed:** release on disconnect for X11, Wayland and headless; Xvfb regression test |
| 6 | `-interface` silently ignored, so `-localhost=0 -interface 10.8.0.1` listened everywhere (SE, EH) | Major | **Fixed:** loopback/any honoured; a specific address is refused rather than widened |
| 7 | A key pressed before QEMU confirmation and released after was released the other way (SE) | Minor | **Fixed:** each key is released the way it was pressed |
| 8 | SIGHUP before the handler existed killed the agent (SE, EH) | Minor | **Fixed:** handler installed first thing |
| 9 | Reload failed open when the keyring was locked (VNC password dropped → None on loopback) (EH) | Minor | **Fixed:** a reload that can't read the keyring is aborted |
| 10 | Imported TigerVNC quality/compression even with AutoSelect on (SE) | Minor | **Fixed:** only with `AutoSelect=0`; test |
| 11 | Compat names as plain files clash with Debian's alternatives (SE) | Minor | **Fixed:** registered with update-alternatives (priority 10); Conflicts with TigerVNC kept (U-11) |
| 12 | TigerVNC's admin `vncserver-config-mandatory` ignored (EH) | Minor | **Fixed:** its `localhost` wins |
| 13 | Common x0vncserver options from unit files were hard errors (SE) | Minor | **Fixed:** accepted with a note; security-relevant ones with a warning |
| 14 | No round-trip/truncation test for QEMU key events; LedState empty payload (EH) | Nit | **Fixed:** tests added |
| 15 | `vncpasswd` silently ignored file / view-only arguments (EH) | Nit | **Fixed:** explains there is no view-only password and no file |
| 16 | Fake `Damaged` event for the QEMU confirmation; magic keysyms; doc comment misplaced (SE) | Nit | **Fixed** |
| 17 | Headless log size not capped (EH) | Minor | **Accepted for now:** owner-only file in the user's runtime dir; rotation with the systemd units (journal) is the recommended path |
| 18 | Agent found by the TigerVNC-viewer interop test: setting a VNC password made the agent panic (keyring read inside the async runtime) | Bug | **Fixed:** credentials load on a blocking thread; covered by CI `viewer-interop` |
