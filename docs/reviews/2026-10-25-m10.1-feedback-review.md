# M10.1 review: fixes from the second install (2026-10-25)

This review covers the user-feedback fixes ([P-55–P-57](../decisions/provisional.md)):

- the Tight width limit;
- remote size and HiDPI fit;
- window buttons off COSMIC;
- Wayland detection and the view-only fallback;
- Farsight Sharing's failure reporting;
- macOS `.dmg` images.

The Senior Engineer and the Security Architect reviewed them.

| # | Persona | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Senior Engineer | Major | "Fit window" did nothing on connect. The size was recorded only on window resizes, which usually happen before the tab exists. | Fixed: the app keeps each window's size and scale, and tabs refit before connection events, menu actions and activation (`App::refit`). |
| 2 | Senior Engineer, Security Architect | Major | The view-only fallback dropped input silently. Viewers, the accept prompt and the logs still said "full control". | Fixed: the capture reports `can_control`, and the agent then runs every session view-only, with a warning. |
| 3 | Senior Engineer | Minor | A doc comment for the settings file had ended up on `wayland_socket_present`. | Fixed |
| 4 | Senior Engineer | Minor | The icon-theme helper was duplicated, and its doc said "on COSMIC" (it means "whenever the Cosmic theme is installed"). | Fixed: there is now one helper, `farsight_desktop::icon_theme::for_libcosmic`, with a corrected doc. |
| 5 | Senior Engineer | Nit | Fractional scales rounded the fit size down. | Fixed (rounded) |
| 6 | Security Architect | Nit | Agent log lines shown in Farsight Sharing kept OSC, control and bidi-override characters, and had no length limit. | Fixed: they are stripped and capped at 300 characters (tested). |
| 7 | Security Architect | Minor | The macOS `.dmg` is unsigned and not notarised, so users have to bypass Gatekeeper. | Still open: Apple Developer ID signing and notarisation is a follow-up. It needs an Apple developer account. |

Checked and fine:

- **Tight:** fill and JPEG rectangles are bounded by `fb.check`. The JPEG decoder is capped at the rectangle's size.
- **`-DesktopSize`:** each side must be 1–16384.
- **ScreenCast-only portal sessions:** they still ask for consent and keep the persistence choice.
- **HiDPI:** the window chrome is subtracted before scaling.
- **Release workflow:** artifacts are named per target, checksums tolerate a missing macOS build, and the `.dmg` files are covered by SHA256SUMS and provenance attestation.
