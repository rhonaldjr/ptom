# Persona review: M8 performance and full encodings (2026-10-24)

Reviewers: Senior Engineer, Security Architect, Ethical Hacker (subagents, read-only).

| # | Finding (who) | Severity | Resolution |
|---|---|---|---|
| 1 | RRE: overlapping full-size subrects let a malicious server make the viewer repaint the screen millions of times for a few bytes (SA, EH) | Major | **Fixed:** total subrect area ≤ 2× the rectangle; regression test |
| 2 | Fence replies claimed SyncNext/BlockAfter, which aren't implemented; a split-read SetPixelFormat could desync a strict viewer (SE) | Major | **Fixed:** replies carry only BlockBefore (in-order handling gives it) on both sides |
| 3 | Disabling continuous updates while already off sent no EndOfContinuousUpdates (SE, SA) | Major | **Fixed:** always confirmed; regression test |
| 4 | Any `FSGT` reply opened the congestion window; stale replies after re-enable widened it (SA, SE, EH) | Minor | **Fixed:** only replies to outstanding fences count; cleared on disable |
| 5 | Fences handled without negotiation; continuous mode kept after the viewer dropped the capability (SA) | Minor | **Fixed** |
| 6 | Viewer treated every EndOfContinuousUpdates as a toggle (SA, SE) | Minor | **Fixed:** the first announces support; later ones only end continuous mode |
| 7 | Blank server desktop name gave an empty tab title (EH) | Minor | **Fixed:** falls back to the address; names sanitised (bidi/control) |
| 8 | `jpeg_capable` duplicated, keyed on depth (SE) | Minor | **Fixed:** one `encode::jpeg_capable`, keyed on 32 bpp and 8-bit channels |
| 9 | Dead match arm; JPEG fallback to Raw; content analysed when nothing can be chosen (SE) | Minor | **Fixed** |
| 10 | Server-session fuzzer never picked Hextile/RRE (SA) | Minor | **Fixed** |
| 11 | Release benchmark step could fail the release; `.txt` not in SHA256SUMS (SA) | Nit | **Fixed** |
| 12 | Hextile encoder function long; per-tile allocations (SE) | Minor | **Accepted for now:** correct and fuzzed; refactor with the M10 encoder work |
| 13 | A server can rename itself to look like another tab (EH) | Minor | **Accepted risk:** the tab still shows the address on hover; recorded in the threat model |
