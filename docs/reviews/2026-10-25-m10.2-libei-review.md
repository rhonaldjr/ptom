# M10.2 review: control on COSMIC through libei, login window (2026-10-25)

This review covers remote input through libei ([P-58](../decisions/provisional.md)) and the longer login window.
The Senior Engineer and Security Architect reviewed it.

| # | Persona | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Senior Engineer | Major | If libei failed after `ConnectToEIS`, the code fell back to the portal's D-Bus input calls, which the portal then refuses | Fixed: a libei failure makes the session "can't control". The agent runs view-only, with a warning. |
| 2 | Senior Engineer | Major | No time limit on the libei handshake | Fixed: 5 s. Tested with a server that never answers. |
| 3 | Senior Engineer | Major | A closed libei connection dropped input silently for the rest of the session | Fixed: the reader marks the connection closed. The capture then ends with "the desktop stopped accepting remote input". Tested. |
| 4 | Senior Engineer | Major | The first region was used, which is wrong with several monitors | Fixed: the region is chosen by the shared stream's mapping ID, or the only region if there is just one. Otherwise motion is dropped, with no guessing. Tested on a two-monitor layout. |
| 5 | Senior Engineer | Minor | AltGr characters (`@`, `€`, `{` on German or French layouts) were lost | Fixed: levels 3 and 4 are mapped and AltGr is pressed (tested on the `de` layout). |
| 6 | Senior Engineer | Minor | The keymap was only read once | Fixed: it is rebuilt each time a keyboard device resumes, which also happens after a layout switch. |
| 7 | Senior Engineer | Minor | Synthetic Shift was released before the key itself | Fixed: synthetic modifiers are held until the key is released. |
| 8 | Senior Engineer | Minor | Drop didn't close the socket | Fixed: our end is shut down, which ends the reader thread. |
| 9 | Security Architect | Minor | 120 s for the whole pre-login phase made slot-holding cheaper | Fixed: 15 s to pick a security type, then 120 s for people to check fingerprints and type passwords. Tested. |
| 10 | Security Architect | Minor | A `--view-only` agent still asked for input control | Fixed: it opens a screen-only session. |
| 11 | Security Architect | Nit | The threat model didn't say that libxkbcommon is a C parser | Fixed (accepted risk: the keymap comes from the user's own compositor). |
